    操作方法 ＆ システムガイド

    🎮 操作方法（SFC風操作系）

    8方向移動矢印 / WASD / テンキー(1-9) / スティック
    斜め移動固定R または Ctrl（斜めのみ移動可能）
    向き変更C または Alt + 方向（ターン消費なしで方向転換）
    ダッシュShift または X + 方向（角・敵に当たるまで一気に直進）
    足踏み. または T（その場で1ターン経過。押しっぱなしで連続）
    攻撃 / 階段Space / Enter / Z（素振りで罠発見）
    持ち物袋I または E
    マップ切替M または Tab（透過オーバーレイ/ミニ/OFF）

    🕹️ コントローラー（Gamepad）

    移動左スティック / 十字キー（D-Pad）
    Aボタン攻撃 / 決定 / 階段を降りる
    Bボタンダッシュ / キャンセル
    Xボタン持ち物袋（インベントリ）
    Yボタン向き変更モード
    R1 / RB斜め移動固定

    🏰 ローグのルール・攻略のコツ

    ・自分が1歩動くと、モンスターも1行動するターン制。
    ・満腹度が0になると1歩ごとにHPが減るので、携帯食糧やパンで補給しましょう。
    ・怪しい通路の曲がり角では「素振り」をすると、隠された罠を発見できます。
    ・ピンチの時は杖や巻物を活用！「位置転換の杖」や「昏睡のスクロール」で難局を切り抜けましょう。
